# Звіт до роботи

## Тема: Тестування з бібліотекою pytest

### Мета роботи

Ознайомитися з бібліотекою pytest для тестування програм мовою Python, навчитися створювати та запускати автоматизовані тести, використовувати параметризацію, фікстури та маркери для перевірки правильності роботи програми.

---

### Виконання роботи

**1. Встановлення бібліотеки pytest**

Для виконання роботи було використано віртуальне середовище Python. Встановлено бібліотеку pytest, яка дозволяє створювати та запускати автоматизовані тести.

Команда для встановлення бібліотеки:

```bash
python3 -m pip install pytest
```

**2. Створення програми для тестування**

Було створено файл `app.py` з класом `Figure`. Клас перевіряє тип геометричної фігури та довжину її сторони. Для перевірки використовуються твердження `assert`, які дозволяють виявити неправильні значення.

Програма підтримує такі типи фігур: трикутник, квадрат, коло та прямокутник. Також реалізовано властивість `get_figure_length`, яка повертає задану довжину.

**3. Створення автоматизованих тестів**

У файлі `test_app.py` було створено тести для перевірки роботи класу `Figure`. Перевірено правильність створення фігур, отримання їхніх властивостей, а також реакцію програми на некоректні дані.

Для запуску тестів використано команду:

```bash
python3 -m pytest -v
```

У результаті виконання всі 19 тестів пройшли успішно.

**4. Використання параметризації**

Для перевірки різних значень використано декоратор `@pytest.mark.parametrize`. Завдяки цьому одну тестову функцію можна виконати з кількома наборами даних.

Було перевірено:

- усі дозволені типи геометричних фігур;
- неправильні типи фігур;
- нульові та від’ємні значення довжини;
- значення довжини, які не є числами.

Це дозволило перевірити роботу програми на різних вхідних даних без створення окремого тесту для кожного випадку.

**5. Використання фікстур**

У роботі використано фікстуру `square`, яка створює об’єкт класу `Figure` з типом «квадрат» і довжиною 10.

Також створено фікстуру `allowed_figures` з параметром `scope="module"`. Вона повертає список дозволених типів фігур і використовується в кількох тестах.

Фікстури допомагають повторно використовувати підготовлені дані та уникати дублювання коду.

**6. Використання маркерів**

Для позначення модульних тестів використано маркер `@pytest.mark.unit`. Його налаштовано у файлі `pyproject.toml`.

Для запуску лише тестів із цим маркером використано команду:

```bash
python3 -m pytest -m unit -v
```

У результаті виконання успішно пройшли 2 тести, а 17 інших тестів не запускалися через фільтрацію за маркером.

**7. Аналіз результатів тестування**

Після запуску повного набору тестів отримано результат:

```text
19 passed in 0.01s
```

Це означає, що всі 19 тестів пройшли успішно. Перевірено правильність роботи класу `Figure`, обробку некоректних значень, використання фікстур і параметризації.

**8. Порівняння unittest і pytest**

`unittest` — стандартна бібліотека Python для написання тестів. Зазвичай тести в ній створюються у класах, які успадковуються від `unittest.TestCase`.

`pytest` — стороння бібліотека, яка дозволяє писати тести у вигляді звичайних функцій, використовувати стандартний оператор `assert`, параметризацію та фікстури. Це робить написання тестів зручним і зрозумілим.

**9. Результати виконання індивідуального завдання**

У результаті виконання роботи створено програму `app.py` і набір автоматизованих тестів `test_app.py`. Усі 19 тестів успішно пройшли перевірку. Також було перевірено можливість запуску окремої групи тестів за допомогою маркера `unit`.

Я навчилася використовувати параметризацію для перевірки різних наборів даних, фікстури для підготовки об’єктів і маркери для вибіркового запуску тестів. Також ознайомилася з основними відмінностями між бібліотеками unittest і pytest.

Формат виконання роботи є зручним, оскільки дозволяє швидко перевіряти програму та виявляти помилки. Для покращення навчального процесу було б корисно додати більше практичних прикладів тестування реальних програм.
